# sadafiiman.github.io

Personal portfolio & resume site for **Iman Sadafi Tehrani** — Senior Software Engineer / Technical Lead, Backend & Distributed Systems.

🔗 **Live site:** [sadafiiman.github.io](https://sadafiiman.github.io/)

## About

This is a single-page Jekyll site hosted on GitHub Pages. It includes:

- Contact links (email, phone, LinkedIn, GitHub)
- A downloadable PDF resume
- About Me summary
- Technical skills
- Work experience
- Personal projects
- Languages, education, and certificates

## Built With

- [Jekyll](https://jekyllrb.com/) (GitHub Pages)
- [Minimal Mistakes](https://mmistakes.github.io/minimal-mistakes/) theme (`splash` layout)
- [Font Awesome](https://fontawesome.com/) for icons


## Updating Content

All page content lives in `index.md` — sections are plain Markdown with a bit of inline HTML/CSS for the contact box and hero subtitle. To update the downloadable resume, replace the PDF file in the repo root and make sure the "Download Resume" link in `index.md` points to the correct filename.
